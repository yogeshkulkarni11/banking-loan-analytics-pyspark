# Data Dictionary

| Column | Description |
|---|---|
| loan_id | Unique loan application identifier |
| customer_id | Customer identifier |
| application_date | Date of loan application |
| loan_type | Home, Personal, Auto, Education or Business |
| loan_amount | Requested loan amount in INR |
| annual_income | Applicant annual income in INR |
| credit_score | Credit score used for risk segmentation |
| employment_type | Employment classification |
| tenure_months | Requested repayment tenure |
| interest_rate | Annual interest rate percentage |
| application_status | Approved or Rejected |
| income_to_loan_ratio | Derived affordability indicator |
| risk_band | Low, Medium or High based on credit score |
| application_month | Derived YYYY-MM reporting period |
